# reflex test
![pcb image](https://github.com/KacperBizon/atmega328_reflex_test/blob/main/reflex_pcb.jpg)

### How to use
- You win by pressing the button on your side faster than your opponent
- To go to the next round press any button for 1s
- Singleplayer - the game finishes with first keypress, multiplayer - both players need to press the keys to finish round 
### Components
- R1 - 10K - reset pullup
- R2-R11 - recommended 3.3k-5.6k
- C1,C1 - 22pF
- C3,C4,C5 - 100nF
- C6 - 10uF
